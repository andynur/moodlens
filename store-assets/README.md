# Chrome Web Store and README Assets

Regenerated for v0.8 on 2026-10-20 with `npm run store:assets`.

## Files

| File | Size | Use |
|---|---|---|
| `icon-128.png` | 128×128 | Store icon. The packaged 16/32/48/128 PNGs live in `public/icons/` and are generated by `npm run icons`. |
| `logo.svg` | vector | Same mark as the icons, for README, social posts and slides. |
| `promo-440x280.jpg` | 440×280 | Small promo tile (required). Locale-neutral, no text. |
| `marquee-en-1400x560.jpg`, `marquee-id-1400x560.jpg` | 1400×560 | Marquee promo tile (optional, used if the store features the item). |
| `hero-en-1280x640.jpg`, `hero-id-1280x640.jpg` | 1280×640 | README banner; also fits the GitHub social preview. |
| `en/`, `id/` | 1280×800 | Five screenshots per locale: Today, Tasks, Practice, AI study answer, AI consent. |

The store takes at most five screenshots; upload the `en/` set to the English listing and the `id/` set to the Indonesian one.

## Provenance and safety

Every image is rendered from `store-preview.html` and `src/store-preview/` with synthetic sites, courses, tasks, cards, XP and a synthetic three-page PDF printed by Chrome. No real student, institution, Moodle account or course data appears. The AI screenshots call no provider: the consent screen shows the real prompt built by `src/shared/ai/prompt.ts`, and the answer is a fixed synthetic reply. The preview harness uses the real side-panel components and styles but is not an input to the production Vite build, so it is absent from `dist/`.

The promo tile and banners are code-authored brand compositions with no third-party artwork. Moodlens does not use the Moodle logo or a university logo, and every screenshot carries the "not affiliated" line.

## Reproduce

```bash
npm run store:assets          # set CHROME_PATH if Chrome is not in the default location
```

The script starts the Vite dev server, drives headless Chrome over a CDP pipe (no extra dependency), performs the clicks each screen needs (reveal answer, load the PDF, review, send) and writes exact-size JPEGs here. Inspect both locales visually before committing. For a single screen during design work, run `npm run dev` and open `/store-preview.html?screen=today&locale=en` (screens: `today`, `tasks`, `practice`, `ai`, `consent`; assets: `?asset=promo|marquee|hero`).
