# PRD-003 — Resource Download Manager

**Feature:** ML-006. **Priority:** P2. **Release:** post-v1 (D-008).

Attendance insight moved to PRD-008.

## Student outcome

Download materials the student can already access, through an explicit, reviewable queue.

## Acceptance criteria (future)

1. Queue contains only student-selected, validated URLs on an enabled site.
2. Filenames are sanitized, previewed and confirmed; count and total size shown.
3. Redirects and intermediate pages handled; failures shown per item.
4. `downloads` permission is added only when the feature ships, with store justification.
5. No silent background downloads; no bypassing restrictions.

## Why post-v1

Several existing extensions already do bulk downloads well (`docs/15_COMPETITIVE_POSITIONING.md`). v1 focuses on features no competitor combines.
