# Localization Contract — English and Bahasa Indonesia

## Requirements

- Every end-user string is a typed key, in both `en` and `id`. From v0.2 the dictionaries live in `src/shared/i18n/en.ts` and `src/shared/i18n/id.ts`; `id` is typed `satisfies Record<TranslationKey, string>` so a missing key fails typecheck.
- A test asserts key parity and no empty values.
- Code, API contracts, commits, docs and agent instructions stay in English.
- Default locale: English. Student can switch to Indonesian; persisted in `chrome.storage.local`. English fallback.
- No machine translation at runtime.
- Indonesian addresses the student informally as "kamu" (possessive "-mu", e.g. "datamu"), never "Anda", in the UI, store listing, privacy policy and "what we never do" page (owner decision 2026-10-20: the audience is university students).
- Dates: `Intl.DateTimeFormat` / `Intl.RelativeTimeFormat` with explicit locale, only for real Moodle timestamps. Show times in the browser's timezone and label it.
- Data from Moodle (course and activity names) is shown as-is, never translated.
- No HTML interpolation from untrusted fields.
- Store listing, privacy policy and "what we never do" page exist in both languages (v0.7).
- Architecture must allow a third locale later without code changes outside `src/shared/i18n/`.

## Key naming

Use dotted namespaces from v0.2: `nav.*`, `today.*`, `tasks.*`, `courses.*`, `practice.*`, `xp.*`, `study.*`, `settings.*`, `site.*`, `error.*`, `consent.*`.

| Key | English | Indonesian |
|---|---|---|
| `nav.today` | Today | Hari ini |
| `nav.tasks` | Tasks | Tugas |
| `status.unknown` | Unknown | Belum diketahui |
| `site.enable` | Enable Moodlens on this site | Aktifkan Moodlens di situs ini |
| `tasks.overdue` | Overdue | Terlambat |
| `guard.active` | Study help is paused during an active assessment. | Bantuan belajar dijeda selama penilaian berlangsung. |

## Language QA

- Switch while panel is open and after reload.
- Long Indonesian labels at 320–400px.
- Empty, error, stale, guard and consent states in both languages.
- Native speaker review before v1.0. Agent pre-review and the reviewer sheet: `docs/releases/v0.9/I18N_REVIEW.md`.
