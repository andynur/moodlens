# Chrome Web Store Assets

Prepared for the v0.7 closed beta on 2026-10-19.

## Files

- `icon-128.png`: store icon. The matching packaged 16/32/48/128 PNGs live in `public/icons/` and are generated by `npm run icons`.
- `promo-440x280.jpg`: locale-neutral small promo tile.
- `en/`: English Today, Tasks and Practice screenshots at 1280×800.
- `id/`: Indonesian versions of the same three screenshots at 1280×800.

## Provenance and safety

Every screenshot is rendered from `store-preview.html` and `src/store-preview/` with synthetic sites, courses, tasks, cards and XP. No real student, institution, Moodle account or course data appears. The preview harness uses the real side-panel components and styles but is not an input to the production Vite build, so it is absent from `dist/`.

The promo tile is a code-authored brand composition with no third-party artwork or logo. It intentionally contains no text so it can be reused for both locales. Moodlens does not use the Moodle logo or a university logo.

## Reproduce the previews

Run `npm run dev`, then open these URLs with the requested viewport:

- Screenshot, 1280×800: `/store-preview.html?screen=today&locale=en`
- Screens: `today`, `tasks`, `practice`
- Locales: `en`, `id`
- Promo, 440×280: `/store-preview.html?asset=promo`

For the Tasks screenshot, scroll the panel until all three synthetic task rows are visible. For Practice, reveal the answer and scroll until the rating buttons and private save offer are visible. Capture the exact viewport, visually inspect both locales, and verify the encoded dimensions before replacing committed assets.
